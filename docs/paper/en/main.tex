% Give TeX a little extra flexibility around long inline identifiers.
% Explicit \bk markers remain the preferred break points; this fallback
% prevents a code fragment from protruding into the margin.
\setlength{\emergencystretch}{1.5em}

% Long code identifiers (\code{PoisonedRetrievalInfluence}) sit in narrow
% table cells. T1 gives a typewriter font that carries hyphenation
% patterns, and hyphenat's htt option switches hyphenation on for it, so
% they wrap instead of running past the column edge. Without the T1
% switch the default OT1 Courier has \hyphenchar disabled and every long
% identifier overflows.
\usepackage[T1]{fontenc}
\usepackage[htt]{hyphenat}

% Floats: keep them near their reference and stop LaTeX deferring a run

% ---------------------------------------------------------------------
% Figures are generated artefacts. Until the figures have been built,
% draw a labelled placeholder instead of failing the build.
% Scaled to fit both the text width and a maximum height, so a diagram
% with an extreme aspect ratio cannot run off the page.
% ---------------------------------------------------------------------
% #1 (optional) is the width as a fraction of \textwidth; the height cap
% only ever binds for a diagram far taller than it is wide.
\newcommand{\safefig}[2][1.0]{%
  \IfFileExists{#2}%
    {\includegraphics[width=#1\textwidth,height=0.4\textheight,keepaspectratio]{#2}}%
    {\fbox{\parbox[c][2.0cm][c]{0.9\textwidth}{\centering
       \ttfamily\scriptsize #2\\[3pt]
       \normalfont\itshape\scriptsize not built --- run the figure builder}}}%
}

% =====================================================================
% TABLE STYLE
%
% The tables carry most of this paper's content, so they are given a
% consistent visual grammar rather than being left as bare booktabs:
%
%   * a tinted header band, with the header text in the same ink as the
%     rules, so the reading order of a wide table is unambiguous;
%   * very light zebra banding, which is what makes an eight-column row
%     traceable across the measure;
%   * a slightly stronger tint for group-header and total rows, so the
%     structure of a multi-block table is visible before it is read;
%   * proportional bars beside the headline rates, so the shape of a
%     column is legible without reading every figure;
%   * semantic colour on the extreme values only -- \hi for the worst
%     outcome in a block, \lo for the best -- never as decoration.
%
% Colours are chosen to stay legible in greyscale: the tints differ in
% lightness, and every emphasised value is also bold.
% =====================================================================
\definecolor{tabhdr}{HTML}{DCE5EE}   % header band
\definecolor{tabgrp}{HTML}{EDF1F6}   % group-header and total rows
\definecolor{tabrow}{HTML}{F6F8FA}   % zebra band
\definecolor{tabink}{HTML}{15334F}   % header text and rules
\definecolor{barfill}{HTML}{4A7CA8}  % filled portion of a rate bar
\definecolor{bartrack}{HTML}{E2E8EE} % unfilled portion of a rate bar
\definecolor{hiviz}{HTML}{9B2226}    % worst outcome in a block
\definecolor{loviz}{HTML}{1B5E3A}    % best outcome in a block

% Booktabs rules and coloured rows fight each other: the default
% \aboverulesep / \belowrulesep leave an uncoloured gap at every rule.
% Zeroing them and paying the space back through \extrarowheight is the
% standard remedy and keeps the bands flush against the rules.
\setlength{\aboverulesep}{0pt}
\setlength{\belowrulesep}{0pt}
\setlength{\extrarowheight}{0.6pt}
\setlength{\heavyrulewidth}{0.9pt}
\setlength{\lightrulewidth}{0.4pt}
\setlength{\cmidrulewidth}{0.35pt}
\arrayrulecolor{tabink}

\setlength{\tabcolsep}{3pt}

\newcolumntype{C}[1]{>{\Centering\arraybackslash}p{#1}}
\newcolumntype{R}[1]{>{\RaggedLeft\arraybackslash}p{#1}}

\newcommand{\totlabel}[1]{\textcolor{tabink}{\textbf{#1}}}

% survives greyscale printing.
\newcommand{\hi}[1]{\textcolor{hiviz}{\textbf{#1}}}
\newcommand{\lo}[1]{\textcolor{loviz}{\textbf{#1}}}

% A proportional bar for a rate in [0,1], drawn as a filled segment over
% a full-width track so the cell occupies the same space at every value.
\newlength{\barwd}
\setlength{\barwd}{9mm}
\newcommand{\asrbar}[1]{%
  \makebox[\barwd][l]{%
    \textcolor{bartrack}{\rule[-0.15ex]{\barwd}{4.5pt}}%
    \hspace*{-\barwd}%
    \textcolor{barfill}{\rule[-0.15ex]{\dimexpr#1\barwd\relax}{4.5pt}}}%
}

% A zero-width break opportunity, no hyphen drawn. Courier carries no
% hyphenation patterns, so long identifiers are given explicit break
% points at CamelCase humps and after path/dot separators; otherwise they
% run straight out of a narrow table cell.
\newcommand{\bk}{\discretionary{}{}{}}

% Table column widths are given as fractions of \textwidth so they track
% the text block instead of being pinned to a page size. The subtracted
% \tabcolsep pays for this column's share of the inter-column padding,
% which guarantees the row cannot exceed the measure.
\newcommand{\tw}[1]{\dimexpr #1\textwidth-2\tabcolsep\relax}

\title{Policy-Aware Security Assessment of an LLM-Backed Web
Application: A Garak-Native Study of Prompt Injection, Information
Disclosure, and Data Poisoning}

\author{Mohammad Mahdi Shahriyar, \quad Hossein Hamzehzadeh, \quad
Kimia Omrani}

\maketitle

\begin{abstract}
Security assessments of large language models usually probe the model,
but the failures that matter in deployment belong to the application
around it --- the input filter, the retriever, the output rewriter, the
file decoder, the tool executor --- because that pipeline is what grants
an untrusted data channel the authority of an instruction channel. We
report an assessment that takes the application as the target. Nine
HTTP surfaces of a deliberately vulnerable LLM-backed shop are wrapped
as Garak generators; twelve detectors test a \emph{specific policy
violation against ground truth} transcribed from the pinned source
rather than a stylistic signature; and the per-attempt secret travels
with the response on Garak's notes channel, which is what makes a
within-process sweep scoreable. An optional LLM-as-a-judge is carried
as a calibrated second opinion, never as a primary detector. Garak core
is unmodified and all 28 runs replay through the stock CLI. Over 678
evaluated attempts, data poisoning is the most exposed category
($\mathrm{ASR}=0.348$); hardening a system prompt across five personas
reduces coupon leakage monotonically from $0.472$ to $0.083$ without
eliminating it; two of ten guardrail configurations perform no better
than no guardrail; success concentrates in techniques that never name
their objective ($14/15$ for fictional framing against $1/15$ for
asking plainly); five mislabelled comments create a targeted classifier
backdoor whose probability drift is measurable four budget steps before
any label changes; trust-tagged retrieval eliminates untrusted
retrieval entirely ($12/12 \to 0/12$); and a stock generic detector
reaches recall $1.000$ at precision $0.293$ against the application's
actual policy. An ablation separates each defensive layer from each
element of the measurement apparatus, and shows that removing the
ground-truth channel does not degrade the study's numbers but abolishes
them.
\end{abstract}

LLM security, prompt injection, data poisoning, information disclosure,
red teaming, garak, LLM-as-a-judge, OWASP LLM Top 10, ablation study.
\end{IEEEkeywords}
