% REFERENCES
%
% The same ten works as the English edition's references.bib, transcribed
% as a literal thebibliography rather than driven through BibTeX. Two
% reasons: IEEEtran.bst emits a .bbl that bidi typesets right-to-left,
% which mangles every author list and arXiv identifier; and a literal
% list has no BibTeX pass to go stale, so `xelatex` twice is the whole
% build.
%
% Each entry is one \lr run covering the whole record, notes included.
% Two failure modes it avoids. An RTL entry with Latin islands puts the
% Persian half on the same line as a wrapped English title, which prints
% the note in the middle of the work it annotates. And bidi's LTR
% environment reverses the direction without switching the font, so ASCII
% commas and page ranges come out as Persian commas and reversed digit
% runs; \lr does both. Every entry therefore stays in the language its
% metadata is recorded in, which is also what a Persian journal does with
% an English-language bibliography.
%
% Scope is the English edition's, unchanged: only sources we hold and
% have read end to end -- two external papers, plus this study's own
% repository and its seven documents. The earlier Persian draft carried
% 27 entries, most of them survey citations to work we had not read;
% those were removed rather than left standing, together with the prose
% that leaned on them.
%
% Entries are numbered by order of first citation, which is what the
% English edition's IEEEtran style produces. Keep this file and the
% English BibTeX database in step -- they are the same bibliography in
% two formats.
% =====================================================================
\renewcommand{\refname}{مراجع}

% Reference entries are short LTR runs inside RTL paragraphs, full of
% material that cannot break -- author initials, DOIs, file paths -- so
% TeX regularly cannot find a break that fills the measure. Justifying
% them means either a loose line or an underfull one, and \sloppy does
% not help because the shortfall is a missing break, not missing stretch.
% Setting the list ragged removes the problem rather than papering over
% it: nothing has to stretch, so nothing comes out underfull, and a
% ragged reference list is ordinary typography.
