# نسخه فارسی مقاله

نسخه نهایی فارسی و تک ستونی مقاله در فایل‌های زیر قرار دارد:

- `paper-fa.tex`: منبع کامل XePersian
- `paper-fa.pdf`: خروجی نهایی و بازبینی‌شده

این نسخه از داده‌های `garak_analysis/` و توضیحات فنی `docs/` استفاده
می‌کند. هر ۹ شکل و ۱۶ جدول نسخه اصلی حفظ شده‌اند و مقاله شامل چکیده،
مقدمه، معماری، روش پژوهش، نتایج، بحث، محدودیت‌ها، نتیجه‌گیری و منابع کامل
است.

## ساخت در Windows

سند به XeTeX و فونت‌های `Tahoma` و `Arial` ویندوز نیاز دارد. در محیطی که
Fontconfig مسیر فونت‌های ویندوز را به صورت خودکار پیدا نمی‌کند، متغیر
`FONTCONFIG_FILE` را به فایل `fonts.conf` همین پوشه تنظیم کنید و سپس
`paper-fa.tex` را با XeLaTeX یا Tectonic بسازید.
