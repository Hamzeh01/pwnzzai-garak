# Glossary

- **Application-layer assessment:** Testing the deployed application behavior, including prompts, state, data, and routes.
- **ASR:** Attack success rate, always reported with numerator and denominator.
- **Attempt:** One controlled interaction under a declared test case, repetition, and state.
- **Automatic label:** Detector-produced outcome before human review.
- **Buff:** Garak component that perturbs or augments attempts.
- **Canary:** Synthetic marker designed for safe, verifiable disclosure detection.
- **Detector:** Rule or model that scores whether an output exhibits the target failure.
- **Generator:** Garak abstraction for the target model or dialog/application system.
- **Manual label:** Human-reviewed final outcome.
- **Poison budget:** Number or ratio of approved poisoned samples.
- **Probe:** Garak component that creates attempts for a target failure mode.
- **Protocol version:** Frozen scenario, detector, parameter, and analysis specification.
- **RAG:** Retrieval-Augmented Generation.
- **System under test (SUT):** The pinned PwnzzAI application and its declared dependencies.
